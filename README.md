# NYC Emergency Department Dashboard — Version 4

Version 4 builds on the validated Version 3.1 dashboard.

## What's included
- Latest-extraction filtering to avoid repeated historical snapshots
- All NYC and MODZCTA geography filtering
- Daily ILI/pneumonia visit trend
- Overall ILI/pneumonia share and admission-rate context
- 7-day rolling rate chart for clearer local trends
- Dynamic “What stands out?” storytelling summaries
- Clearer interpretation guidance and source/extraction footer
- Responsive layout refinements for smaller screens
- Loading, timeout, error, and retry states

## Run locally
```bash
npm install
npm run dev
```
